# Cross-border customs agent demo (#1364)

这是四模块跨境报关自动化的**合成数据 demo**，用于让甲方先看流程、产物和人工确认边界。它不是生产系统，不接真实 ERP/DingTalk/电子税务局。

## 四模块
1. **订单/合同/产品报关知识**：产品-HS-申报要素-订单-合同字段字典；新品进入待确认清单；合同金额/订单/产品一致性检查。
2. **报关发货回填**：组合品 BOM 拆分、套装/箱/件单位换算、多批次、合并申报、部分申报、缺失字段异常表、变更留痕。
3. **发票/合同/报关比对 + 电子税务局半自动化**：发票、合同、报关差异分级；电子税务局只生成预览，必须人工确认；demo 中未确认的提交会被拒绝。
4. **发票回填/剩余数量**：发票行回填到订单，计算已开票/剩余数量；本地 VM/本地模型路径只做说明，不上传数据。

## 快速开始

要求 Python 3.10+，只用标准库。

```bash
cd customs-agent
python customs_agent.py demo
python -m unittest discover -s tests -v
```

## 验收口径
- 50 批次字段一致性：demo 为 100%，验收要求 >= 99.5%；
- 模块 2/3/4 均可运行，源码 + 部署说明 + 操作手册 + 测试 + 验证记录；
- 电子税务局提交必须人工确认，demo 中没有无人申报路径；
- 所有采购/第三方费用另计，不含在本 demo。

## 边界
- 数据全部为合成数据，不含真实客户、订单、发票或税号。
- 不接真实税局/ERP/DingTalk；不保存税局密码；不做无人值守申报。
- 本地 VM/本地模型为部署路径说明，demo 只演示字段抽取前的业务流。
- 50 批次是脱敏样例，不等于真实 50 批数据的 99.5% 已验收。

## 测试覆盖
`tests/test_customs_agent.py` 覆盖：BOM 拆分/单位换算、缺失字段异常、合并申报、部分申报、50 批次一致性、发票税号差异、电子税务局人工确认门禁、剩余数量、新品确认和完整 demo。

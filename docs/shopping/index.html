Delivery notes

        
这套样例对应什么交付

        
    
          
  • C 端 MVP：AI Search 卡片 / 聊天助手 / 导购 Bot，按品类配置回答口吻与风险阈值。
    • 
          
  • B 端 MVP：结构化推荐 API、品牌可见度/引用监测、知识库质量报表。
    • 
          
  • 模型层：RAG 检索 + 规则引擎 + 可替换 LLM；高风险结论必须保留 citation 与人工复核入口。
    • 
          
  • 验收口径：推荐可追溯率 100%、高风险宣称漏检率 0、同一输入结果稳定、无来源结论不展示。
    •

Always-on, by design

关机也能打开，因为页面根本不在你的电脑上跑。

所有演示都是静态 HTML/CSS/JS，部署在 GitHub Pages 的 CDN 上。没有本地服务、没有数据库、没有定时任务；你合上电脑，链接仍然可以在手机或另一台电脑打开。演示中的“运行”只是浏览器内确定性计算，不会访问真实客户系统。

✓静态托管：GitHub Pages CDN无需本机进程
✓无密钥：不读取任何 API key可公开分享
✓确定性数据：同输入同输出方便复核
✓移动端可用：响应式布局手机可验收

验收看什么

先打开任一 demo，点“运行自检”。自检项是断言，不是文案：抽取字段、证据完整性、规则判定、结算总和、API 契约都会被逐项检查。

源码在哪

完整源码树在 Gupeat/clawhunt-agent-demos；本页与六个 demo 都放在 docs/，可一键 fork 或私有化部署。

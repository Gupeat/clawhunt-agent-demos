交付格式

CSV（UTF-8 with BOM）可直接用 Excel 打开；字段名使用英文 snake_case，日期 ISO 8601，金额为两位小数。另附本页处理说明与异常清单。

不做什么

不覆盖源文件；不猜缺失邮箱/日期/金额；不把重复行合并金额；不在未确认时删除异常行。所有无法自动判定的内容都留给人工。

输入先对齐

先确认用途、字段、缺失/重复/格式规则、交付格式。需求不清时先出 10 行试洗，不直接批量改全表。

结果可复核

每行保留原始行号；每个异常保留原始值与原因；可下载结果与处理说明，抽样 10% 人工复核。

边界说清楚

清洗不等于补全。缺失值、歧义日期、跨系统 ID 映射要业务确认；本演示不连接你的网盘、邮箱或数据库。
